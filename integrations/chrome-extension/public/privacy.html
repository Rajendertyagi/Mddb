MDDB Browser — Privacy policy

Last updated: 2026-05-21. The canonical, always-current Tradik Limited privacy policy lives at https://tradik.com/privacy. This bundled copy describes the extension itself, so it stays available even when offline.

1. Data we collect

The MDDB Browser extension does not collect, transmit, sell, or share any personal information. It does not contain analytics, telemetry, advertising SDKs, tracking pixels, or third-party calls of any kind.

2. Data stored locally

The only data the extension stores lives inside your browser profile via the chrome.storage.local API and never leaves your device:

  • The MDDB server URL you configured.
  • The optional MDDB API key you configured.
  • The optional admin panel URL you configured.
  • The background refresh interval you chose.
  • A cached copy of the most recent GET /v1/stats response, used to keep the toolbar badge counter fresh without re-querying on every popup open.

Removing the extension (Chrome → Extensions → Remove) wipes all of the above immediately and completely.

3. Network requests

The extension only contacts the MDDB server URL you configure. It calls the public endpoints GET /v1/health and GET /v1/stats and — if you set one — sends the API key as an X-API-Key header. No other host is ever contacted by the extension itself.

4. Permissions explained

  • storage — persists the settings and stats cache listed in section 2.
  • alarms — schedules the background poll that refreshes the badge counter.
  • optional_host_permissions: http://*/*, https://*/* — requested only for the hostname of the MDDB server you configure, so the extension can make the fetch() calls described in section 3. No permission is requested until you actually save a URL.

5. Children's privacy

The extension is a developer tool. It is not directed at children under 13 and we do not knowingly collect data from anyone.

6. Changes to this policy

If we ever change what the extension stores or where it sends data, the change will be documented in CHANGELOG.md and shipped in a new release. For the Tradik corporate policy (analytics, contact handling, your data-protection rights) see https://tradik.com/privacy.

7. Contact

Questions or concerns: open an issue at https://github.com/tradik/mddb/issues or use the contact form linked from tradik.com/contact.
